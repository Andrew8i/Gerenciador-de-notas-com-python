Gerenciador de Notas

📌 Descrição

Este projeto é um sistema simples de gerenciamento de notas, desenvolvido em Python. Ele permite criar, modificar, visualizar e excluir notas de forma organizada.

🚀 Funcionalidades

📜 Listar todas as notas - Exibe todas as notas cadastradas.

📌 Exibir uma nota pelo ID - Permite visualizar o conteúdo de uma nota específica.

➕ Adicionar uma nova nota - Cria uma nova nota com título e conteúdo.

✏️ Editar uma nota existente - Modifica o título ou o conteúdo de uma nota cadastrada.

❌ Excluir uma nota - Remove uma nota da lista.

🛠 Tecnologias

Python

📖 Como Usar

Execute o script Python em seu terminal ou ambiente de desenvolvimento.

Interaja com o sistema para adicionar, modificar, visualizar ou excluir notas.
